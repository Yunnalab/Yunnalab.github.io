> 适用题型：命题真假判断、数列极限计算、函数极限不存在性证明

## 一、核心桥梁：海涅定理（归结原则）

$$\lim_{x\to x_0}f(x)=a \iff \text{对任意 }x_n\to x_0\ (x_n\ne x_0)\text{ 都有 } \lim_{n\to\infty}f(x_n)=a$$

$x\to+\infty$ 版本：

$$\lim_{x\to+\infty}f(x)=a \iff \text{对任意 }x_n\to+\infty\text{ 都有 } f(x_n)\to a$$

这一条是**所有「数列 ↔ 函数」题目的总开关**，两个方向都要注意：

| 方向 | 成立性 | 典型用法 |
|---|---|---|
| 函数极限 ⇒ 数列极限 | **正向、无条件成立** | 把 $f(n)$ 看作 $f(x)$ 的采样点，用洛必达 / 泰勒 / 等价无穷小求数列极限 |
| 数列极限 ⇒ 函数极限 | **必须附加「任意数列」或额外条件** | 用两个子列极限不同来**证明函数极限不存在** |

## 二、单向性：到底谁推谁

设同一表达式 $f$，$a$ 为常数。

| 命题 | 真假 | 原因 / 反例 |
|---|---|---|
| $\lim\limits_{x\to+\infty}f(x)=a \Rightarrow \lim\limits_{n\to\infty}f(n)=a$ | ✅ 真 | 取 $x_n=n$，海涅定理 |
| $\lim\limits_{n\to\infty}f(n)=a \Rightarrow \lim\limits_{x\to+\infty}f(x)=a$ | ❌ 假 | $f(x)=\sin 2\pi x$：$f(n)\to0$，但 $\lim\limits_{x\to+\infty}\sin2\pi x$ 不存在 |
| $\lim\limits_{x\to x_0}f(x)=a,\ x_n\to x_0 \Rightarrow f(x_n)\to a$ | ❌ 假 | 缺 $x_n\ne x_0$。$f=\begin{cases}1,&x\ne0\\0,&x=0\end{cases}$，$x_n\equiv0$ 时 $f(x_n)=0\ne1$ |
| $\lim\limits_{x\to x_0}f(x)=a,\ x_n\to x_0,\ x_n\ne x_0 \Rightarrow f(x_n)\to a$ | ✅ 真 | 海涅定理 |
| $f(x_n)\to a$（仅**某一个**数列）$\Rightarrow \lim\limits_{x\to x_0}f(x)=a$ | ❌ 假 | 只给出一条路径的信息。$f(x)=\sin\frac1x,\ f(0)=0$，取 $x_n=\frac1{2n\pi}$ 得 $f(x_n)\to0$，但取 $y_n=\frac{1}{2n\pi+\pi/2}$ 得 $f(y_n)\to1$。**详见 §2.1** |
| 对**任意** $x_n\to x_0\ (x_n\ne x_0)$ 都有 $f(x_n)\to a$ $\Rightarrow \lim\limits_{x\to x_0}f(x)=a$ | ✅ 真 | 海涅定理逆用（用于证明存在性） |

### 2.1 为什么「仅某一个数列收敛」推不出函数极限？

**关键区别：一个数列 = 一条路径；函数极限 = 所有路径。**

设 $x_0=0$，要去判断 $\lim\limits_{x\to0}f(x)$ 是否存在。题目只告诉你**某一个** $x_n\to0$ 上 $f(x_n)\to a$，这相当于只报告了**一条曲线上的读数**，而 $x\to0$ 有不可数无穷多条路径（$x\to0^+$、$x\to0^-$、沿 $\frac1{n}$、沿 $\frac{1}{n\pi}$……）。

**完整反例（把这个例子记住，②③④都能用它）**

$$f(x)=\sin\frac1x\ (x\ne0),\qquad f(0)=0,\qquad x_0=0,\qquad a=0$$

| 步骤 | 内容 |
|---|---|
| ① 验证**前提**成立 | 取 $x_n=\dfrac{1}{2n\pi}\to0$，则 $f(x_n)=\sin(2n\pi)=0$，故 $f(x_n)\to0=a$ ✅ |
| ② 验证**结论**不成立 | 再取 $y_n=\dfrac{1}{2n\pi+\pi/2}\to0$，则 $f(y_n)=\sin\left(2n\pi+\dfrac{\pi}{2}\right)=1$，故 $f(y_n)\to1\ne0$ |
| ③ 结论 | 两个子列 $\to0$ 的函数值极限不同（$0$ 与 $1$），由海涅定理 **$\lim\limits_{x\to0}\sin\frac1x$ 不存在**，命题为假 |

**逻辑本质：必要条件 ≠ 充分条件**

$$\lim_{x\to x_0}f(x)=a \;\Longrightarrow\; f(x_n)\to a\ \text{（对每个数列都成立）}$$

反方向要成立，量词必须从「存在一个数列」升级为「**任意**数列」：

| 量词 | 形式 | 真假 |
|---|---|---|
| 存在 | $\exists\{x_n\}:f(x_n)\to a$ | ❌ 推不出 |
| 任意 | $\forall\{x_n\}\ (x_n\ne x_0):f(x_n)\to a$ | ✅ 充要条件 |

**同一逻辑漏洞的三种表现**（② 把「整数点」当成「所有点」，④ 把「一条路径」当成「所有路径」）：

| 题号 | 趋向 | 仅有信息 | 漏洞 |
|---|---|---|---|
| ② | $x\to+\infty$ | $f$ 在 $\{1,2,3,\dots\}$ 上收敛 | 忽略了非整数点，$\sin2\pi x$ 在整数点全是 0 |
| ④ | $x\to x_0$ | $f$ 在一条趋于 $x_0$ 的路径上收敛 | 忽略了其他路径，$\sin\frac1x$ 沿另一条路径 → 1 |

> 记住形态：**只要题目试图从「某条路径/某个子集上的收敛」推出「整体极限存在」，一律先找反例。**
> 常用反例就三个：$\sin\frac1x$（振荡，配 $\frac{1}{2n\pi}$ 与 $\frac{1}{2n\pi+\pi/2}$）、$\sin 2\pi x$（整数点全为 0）、分段常数（某一列取到孤立值）。

**一句话记忆**

> 函数极限 ⟹ 数列极限（无条件）；
> 数列极限 ⟹ 函数极限（需「任意数列」，或加**单调性**等额外条件）。

**唯一的常用补充定理**

> 若 $f$ 在 $[1,+\infty)$ 上**单调**，且 $\lim\limits_{n\to\infty}f(n)=a$，则 $\lim\limits_{x\to+\infty}f(x)=a$。

单调性排除了「整数点恰好落在零点或峰谷上」的振荡漏洞。典型反例 $\sin 2\pi x$ 正是非单调。

## 三、差异的根源

| | 数列 $f(n)$ | 函数 $f(x)$ |
|---|---|---|
| 趋向方式 | 只有一种：$n\to\infty$，**单调地**离散逼近 | 有无穷多条路径（左右、上下、绕行、振荡） |
| 采样点 | 只取整数点 | 取遍连续统 |
| 要求强度 | 弱（只约束一条稀疏轨道） | 强（要求所有路径都趋向同一值） |

所以：**数列极限是函数极限的弱化版（必要条件）**。

本质直觉：

> 数列极限 ≈ 函数在某**一个**趋向路径上的极限；
> 函数极限 = 在**所有**路径上的极限，且都相等。

这正是**证明函数极限不存在**的标准套路：找两条路径（两个子列）极限不等，或找一条路径使极限不存在。

## 四、可以互相迁移的性质（两边都成立）

把 "$x\to x_0$" 换成 "$n\to\infty$"，下列性质几乎逐字照搬：

| 性质 | 函数版 | 数列版 |
|---|---|---|
| 唯一性 | 极限唯一 | 极限唯一 |
| 局部有界性 | $\lim f=a$ ⇒ $f$ 在 $x_0$ 某去心邻域有界 | $\lim a_n=a$ ⇒ $\{a_n\}$ 有界 |
| 局部保号性 | $\lim\limits_{x\to x_0}f=a>0$ ⇒ 某邻域内 $f>0$ | $a_n\to a>0$ ⇒ 从某项起 $a_n>0$ |
| 四则运算 | 和差积商（分母极限非 0） | 同 |
| 夹逼定理 | $g\le f\le h,\ \lim g=\lim h=a$ ⇒ $\lim f=a$ | 同 |
| 柯西收敛准则 | $\forall\varepsilon\exists\delta,\ 0<\lvert x-x_0\rvert<\delta$ 时 $\lvert f(x)-f(y)\rvert<\varepsilon$ | $\forall\varepsilon\exists N,\ m,n>N$ 时 $\lvert a_m-a_n\rvert<\varepsilon$ |
| 单调有界原理 | 单调且有界 ⇒ 极限存在 | 单调且有界 ⇒ 收敛 |
| 无穷小 × 有界 = 无穷小 | ✅ | ✅ |
| 等价无穷小替换 | ✅（乘除可换，加减慎用） | ✅ |

> 等价无穷小在数列中成立的理由正是海涅定理：$\frac1n\to0 \Rightarrow n\sin\frac1n \sim n\cdot\frac1n = 1$。

## 五、不能迁移 / 容易踩坑的工具

| 工具 | 能否用于数列 | 说明 |
|---|---|---|
| **洛必达法则** | ⚠️ 不能直接对 $n$ 求导 | 数列不可导。做法：设连续函数 $f(x)$，先求 $\lim\limits_{x\to+\infty}f(x)$；若存在，则数列极限同值（这正是命题①的用法） |
| **斯托尔兹定理** | 数列专用 | 洛必达的「离散版」，用于 $\frac{a_n}{b_n}$ 型数列极限 |
| **子列法** | 两边都能用 | 数列：两个子列极限不同 ⇒ 原极限不存在；函数：两条路径极限不同 ⇒ 极限不存在 |
| **泰勒 / 导数 / 中值定理** | 需先「连续化」 | 必须先构造 $f(x)$，再用海涅定理把结果搬回数列 |
| **$x\to x_0$ 的左右极限** | 数列无对应 | 数列只有一种趋向；函数有 $x\to x_0^-$、$x\to x_0^+$ |
| **连续性** | 数列不需要 | 若加上「$f$ 在 $x_0$ 连续」或「$x_n\ne x_0$」，才能由 $x_n\to x_0$ 推出 $f(x_n)\to f(x_0)$ |

## 六、解题套路

### 1. 求数列极限（"生"的函数）

- 令 $x=\frac1n$，或直接设 $f(x)$，求 $\lim\limits_{x\to+\infty}f(x)$；
- 用洛必达、泰勒展开、等价无穷小；
- 结论：函数极限存在 ⟹ 数列极限 = 该值（命题①）。

### 2. 证明函数极限不存在

- 找满足条件的 $x_n\to x_0$ 使 $f(x_n)$ 不收敛；
- 或找两个 $x_n,\ y_n\to x_0$ 使 $f(x_n)\to a,\ f(y_n)\to b,\ a\ne b$；
- 常见构造：$x_n=\dfrac{1}{2n\pi}$ 与 $y_n=\dfrac{1}{(2n+1)\pi}$（对付 $\sin\frac1x$、$\cos\frac1x$）。

### 3. 判断题的检查清单

1. 有没有「**任意**数列」这个量词？
2. 有没有 $x_n\ne x_0$ 这个约束？
3. 题目有没有偷偷假设**单调 / 连续 / 有界**？
4. 反例优先想：$\sin\frac1x$、$\sin2\pi x$、分段常数、「孤立点 / 常数列」。

## 七、真题示例

**题目**（来源：考研数学一选择 3）

给出以下 4 个命题：

1. 若 $\lim\limits_{x\to+\infty}f(x)=a$，则 $\lim\limits_{n\to\infty}f(n)=a$；
2. 若 $\lim\limits_{n\to\infty}f(n)=a$，则 $\lim\limits_{x\to+\infty}f(x)=a$；
3. 若 $\lim\limits_{x\to x_0}f(x)=a$，且 $\lim\limits_{n\to\infty}x_n=x_0$，则 $\lim\limits_{n\to\infty}f(x_n)=a$；
4. 若 $\lim\limits_{n\to\infty}x_n=x_0$，且 $\lim\limits_{n\to\infty}f(x_n)=a$，则 $\lim\limits_{x\to x_0}f(x)=a$。

其中真命题个数为（　　）　(A) 0　(B) 1　(C) 2　(D) 3

**解答**

- **① 真**：取 $x_n=n\to+\infty$，由海涅定理直接得。
- **② 假**：$f(x)=\sin2\pi x$，$f(n)=0\to0$，但 $\lim\limits_{x\to+\infty}\sin2\pi x$ 不存在。
- **③ 假**：缺 $x_n\ne x_0$。$f(x)=\begin{cases}1,&x\ne0\\0,&x=0\end{cases}$，$x_0=0$ 时 $\lim\limits_{x\to0}f(x)=1$，取 $x_n\equiv0$ 得 $f(x_n)=0\to0\ne1$。
- **④ 假**：「一条路径收敛」推不出「整体收敛」。取 $f(x)=\sin\frac1x\,(x\ne0),\ f(0)=0$，$x_0=0$，$a=0$：
  - 取 $x_n=\dfrac{1}{2n\pi}\to0$，则 $f(x_n)=\sin(2n\pi)=0\to0=a$ —— **前提成立**；
  - 但取 $y_n=\dfrac{1}{2n\pi+\pi/2}\to0$，则 $f(y_n)=1\to1\ne a$；
  - 两子列极限不同 ⇒ $\lim\limits_{x\to0}\sin\frac1x$ 不存在 ⇒ **结论不成立**。

真命题只有 ①，个数为 **1**，选 **(B)**。

> 另注：③ 若补上条件 $x_n\ne x_0$，就变成真命题 —— 这是考研中的经典陷阱。
>
> ② 与 ④ 是**同一个漏洞的两种形态**：都试图从「某个子集 / 某条路径上的收敛」去推「整体极限存在」。

---

## 八、一句话收尾

> **离散是连续的采样，连续是离散的完备。**
> 数列极限只是函数极限的一个必要投影；函数极限要求「条条大路通 $a$」，数列极限只保证「整数这条小路通 $a$」——
> 所以 **函数 ⇒ 数列（真），数列 ⇒ 函数（假，除非补条件）**。
