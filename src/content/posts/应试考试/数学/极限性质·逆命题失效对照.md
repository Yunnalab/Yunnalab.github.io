> 考研高数 · 极限理论核心易错点
>
> 核心结论：**收敛 $\Rightarrow$ 有界**、**极限正 $\Rightarrow$ 局部正**，两条都是单向的。
>
> 适用题型：命题真假判断、反例构造、$\varepsilon$-$\delta$ 放缩的前置引理。

---

# 一、两条性质的准确表述

## 1.1 数列版

**有界性**：$\{a_n\}$ 收敛 $\Rightarrow$ $\{a_n\}$ 有界，即 $\exists M>0,\ \forall n\in\mathbb N^*,\ \lvert a_n\rvert\le M$。

**保号性**：设 $\lim\limits_{n\to\infty}a_n=a$，则

$$a>0 \;\Rightarrow\; \exists N,\ \forall n>N,\ a_n>0 \qquad\left(\text{更强：} a_n>\frac a2>0\right)$$

$$a<0 \;\Rightarrow\; \exists N,\ \forall n>N,\ a_n<0$$

## 1.2 函数版

**局部有界性**：$\lim\limits_{x\to x_0}f(x)=A$ $\Rightarrow$ $\exists\delta>0,\ \exists M>0$，$\forall x\in\mathring U(x_0,\delta)$ 有 $\lvert f(x)\rvert\le M$。

**局部保号性**：设 $\lim\limits_{x\to x_0}f(x)=A$，则

$$A>0 \;\Rightarrow\; \exists\delta>0,\ \forall x\in\mathring U(x_0,\delta),\ f(x)>\frac A2>0$$

$$A<0 \;\Rightarrow\; \exists\delta>0,\ \forall x\in\mathring U(x_0,\delta),\ f(x)<\frac A2<0$$

$x\to\infty$ 版：把 $\mathring U(x_0,\delta)$ 换成 $\lvert x\rvert>X$（或 $x>X$）。

## 1.3 三个必须记住的措辞差异

| 项目 | 数列 | 函数 |
|---|---|---|
| "局部"的范围 | 从某项起 $n>N$ | 去心邻域 $\mathring U(x_0,\delta)$ |
| 有界的强度 | **整体**有界 | **局部**（尾部）有界 |
| 首项 / $f(x_0)$ | 只影响 $M$ 的取值 | **完全不参与**，可任意、可无定义 |

> **"去心"二字很关键**：$f(x_0)$ 的值与极限无关，所以既不参与保号性，也不参与局部有界性。数列没有这个自由度——每一项都必须参与。

# 二、失效的统一机制

反向不成立，来自两个各自独立的漏洞。

**漏洞一：有界只锁振幅，不锁去向。**
有界给出的是"范围"信息；收敛还要求"稳定下来"（振幅趋于 $0$）。有界少了一个条件——单调性，或"所有子列同极限"。

**漏洞二：取极限把"$>$"做成"$\ge$"。**
极限是"取闭包"的操作，严格不等号在极限过程后会退化为不严格不等号。所以规则是：

> **严格进、严格出；非严格进、只能非严格出。**
> $A>0 \Rightarrow$ 局部 $f>0$（严格进，可以严格出）
> 局部 $f>0 \Rightarrow A\ge0$（非严格进，只能非严格出）

# 三、有界性：反向失效全解

## 3.1 数列版

**反例**：

$$a_n=(-1)^n:\qquad \lvert a_n\rvert=1 \ \text{有界，但在} \ -1,1 \ \text{之间振荡，不收敛}$$

发散的完整分类（易错点）：

$$\text{发散} \;=\; \underbrace{\text{无界发散}}_{n,\ (-2)^n,\ n\sin n} \;\cup\; \underbrace{\text{有界发散（振荡）}}_{(-1)^n,\ \sin n}$$

因此只能写"**无界 $\Rightarrow$ 发散**"，不能写"**发散 $\Rightarrow$ 无界**"。

## 3.2 函数版：注意"局部"二字

$$f(x)=x \ \text{在} \ x_0=0 \ \text{处局部有界，但在} \ \mathbb R \ \text{上整体无界}$$

局部有界 $\nRightarrow$ 极限存在：

$$f(x)=\sin\frac1x\ (x\ne0),\quad x_0=0:\qquad \lvert f\rvert\le1 \ \text{局部有界，但} \ \lim_{x\to0}\sin\frac1x \ \text{不存在}$$

更彻底的反例（**通杀型**，记住它）：

$$D(x)=\begin{cases}1,&x\in\mathbb Q\\0,&x\in\mathbb R\setminus\mathbb Q\end{cases}$$

$\lvert D\rvert\le1$ 处处有界，但在**任何**点极限都不存在（取有理数列得 $1$、无理数列得 $0$，用海涅定理）。

函数特有的"极限不存在"三分法（数列只有尾部一个方向，函数有左右）：

$$\underbrace{\frac1x}_{\text{无界发散}}\qquad \underbrace{\sin\frac1x}_{\text{有界振荡}}\qquad \underbrace{\operatorname{sgn}x}_{\text{左右极限不等}}$$

## 3.3 "有界"到底能推出什么

| 命题 | 真假 | 反例 / 依据 |
|---|---|---|
| 收敛 $\Rightarrow$ 有界 | 真 | 取 $\varepsilon=1$，$M=\max\{\lvert a_1\rvert,\dots,\lvert a_N\rvert,\lvert a\rvert+1\}$ |
| 有界 $\Rightarrow$ 收敛 | 假 | $(-1)^n$ |
| 无界 $\Rightarrow$ 发散 | 真 | 上一条的逆否命题 |
| 发散 $\Rightarrow$ 无界 | 假 | $(-1)^n$ |
| 有界 $\Rightarrow$ **存在收敛子列** | 真 | 魏尔斯特拉斯（致密性）定理 |
| 有界 $+$ 单调 $\Rightarrow$ 收敛 | 真 | 单调有界准则，两条件缺一不可 |
| 子列收敛 $\Rightarrow$ 整体收敛 | 假 | $(-1)^n$：$a_{2k}\to1$，$a_{2k-1}\to-1$ |
| **所有**子列收敛且同极限 $\Rightarrow$ 收敛 | 真 | 证明收敛的常用手段 |
| 收敛 $\Rightarrow$ $\lvert a_n\rvert$ 收敛 | 真 | — |
| $\lvert a_n\rvert$ 收敛 $\Rightarrow$ 收敛 | 假 | $(-1)^n$ |
| 极限存在 $\Rightarrow$ **局部**有界 | 真 | 局部有界性，$M=\lvert A\rvert+1$ |
| 局部有界 $\Rightarrow$ 极限存在 | 假 | $\sin\frac1x$、$D(x)$ |
| 整体有界 $\Rightarrow$ 局部有界 | 真 | 整体强于局部 |
| 局部有界 $\Rightarrow$ 整体有界 | 假 | $f(x)=x$ |
| 单调有界 $\Rightarrow$ 单侧极限存在 | 真 | 函数版单调有界准则 |

**函数版单调有界准则**（比数列版更有用）：

$$f \ \text{在} \ (a,b) \ \text{上单调有界} \;\Longrightarrow\; f(a+0),\ f(b-0) \ \text{都存在（有限）}$$

推论：**单调函数的间断点只能是跳跃间断点**（选择题高频结论）。
$x\to+\infty$ 版：$f$ 在 $[a,+\infty)$ 上单调有界 $\Rightarrow \lim\limits_{x\to+\infty}f(x)$ 存在。

# 四、保号性：反向失效全解

## 4.1 四象限真值表（函数版）

极限记为 $A$。数列版把"邻域"读作"从某项起"，结论完全不变。

| 前件 | 结论 | 真假 | 反例 |
|---|---|---|---|
| $A>0$ | 局部 $f>0$ | 真 | — |
| $A\ge0$ | 局部 $f\ge0$ | 假 | $A=0$，$f(x)=-\lvert x\rvert$，$x_0=0$ |
| 局部 $f>0$ 且极限存在 | $A>0$ | 假 | $f(x)=x$，$x_0=0$：$(0,\delta)$ 上 $f>0$，但 $A=0$ |
| 局部 $f\ge0$ 且极限存在 | $A\ge0$ | 真 | **正确的逆命题形式**，但只有 $\ge$ |

数列对应：

| 前件 | 结论 | 真假 | 反例 |
|---|---|---|---|
| $a>0$ | 从某项起 $a_n>0$ | 真 | — |
| $a_n>0\ (\forall n)$ | $a>0$ | 假 | $a_n=\dfrac1n$ |
| $a_n\ge0\ (\forall n)$ | $a\ge0$ | 真 | — |
| $a=0$ | $\{a_n\}$ 定号 | 假 | $a_n=\dfrac{(-1)^n}{n}$ 正负交替 |

## 4.2 两个"打通一切"的反例

$$a_n=\frac1n>0 \ \text{恒正},\qquad \lim_{n\to\infty}a_n=0\;\not>0$$

$$f(x)=x,\quad x_0=0:\qquad \lim_{x\to0}x=0$$

第二个更狠：对**任意** $\delta>0$，在 $\mathring U(0,\delta)=(-\delta,0)\cup(0,\delta)$ 内 $f$ 时正时负，极限却存在。这一条直接击破"极限存在 $\Rightarrow$ 局部定号"。

> 数列版要"不定号"必须正负交替（如 $\frac{(-1)^n}{n}$）；函数版因为邻域是双侧的，同一个邻域里正负都有，不定号是**天然**的。

## 4.3 保序性（相对形式）

$f(x)\le g(x)$ 在 $\mathring U(x_0,\delta)$ 内成立、两极限都存在 $\Rightarrow A\le B$。

| 前件 | 结论 | 真假 | 反例 |
|---|---|---|---|
| $f\le g$ 局部 | $A\le B$ | 真 | — |
| $f<g$ 局部 | $A<B$ | 假 | $f=0$，$g=\lvert x\rvert$，$A=B=0$ |
| $A<B$ | $f<g$ 从某邻域起 | 真 | 严格进严格出 |
| $A\le B$ | $f\le g$ 局部 | 假 | $A=B=0$，$f=x$，$g=-x$ |
| $f\le g$ 且 $A=B$ | 局部 $f=g$ | 假 | 得不到任何信息 |

记忆：**"$\ge$ 进 $\ge$ 出，$>$ 进才能 $>$ 出"**。

# 五、两个加强版（放缩题必备）

## 5.1 极限非零 $\Rightarrow$ 局部有正下界

$$\lim_{x\to x_0}f(x)=A\ne0 \;\Longrightarrow\; \exists\delta>0,\ \forall x\in\mathring U(x_0,\delta),\ \lvert f(x)\rvert>\frac{\lvert A\rvert}{2}>0$$

**证明**：取 $\varepsilon=\dfrac{\lvert A\rvert}{2}$，由 $\lvert f(x)-A\rvert<\dfrac{\lvert A\rvert}{2}$ 得

$$\lvert f(x)\rvert\;\ge\;\lvert A\rvert-\lvert f(x)-A\rvert\;>\;\frac{\lvert A\rvert}{2}$$

数列版：$\lim a_n=a\ne0 \Rightarrow \exists N,\ \forall n>N,\ \lvert a_n\rvert>\dfrac{\lvert a\rvert}{2}>0$。

**用途**：$\dfrac1{f(x)}$ 局部有界、洛必达法则前提、夹逼放缩、无穷小比较、级数比较判别法。

## 5.2 收敛的证明过程本身就是局部估计

取 $\varepsilon=1$ 得 $\lvert f(x)\rvert<\lvert A\rvert+1$——这正是局部有界性的证明。数列版是 $\lvert a_n\rvert<\lvert a\rvert+1$，一一对应。

> 所有 $\varepsilon$-$\delta$ / $\varepsilon$-$N$ 放缩题都从这个估计起步：**先把极限换成"常数 $+$ 小量"，再用三角不等式削出可用的上界或下界。**

# 七、反例库（背这些就够）

| 反例 | 用来击破 |
|---|---|
| $a_n=(-1)^n$ | 有界 $\Rightarrow$ 收敛；发散 $\Rightarrow$ 无界；$\lvert a_n\rvert$ 收敛 $\Rightarrow$ 收敛 |
| $a_n=\dfrac1n$ | $a_n>0 \Rightarrow$ 极限 $>0$ |
| $a_n=\dfrac{(-1)^n}{n}$ | 极限为 $0 \Rightarrow$ 定号 |
| $a_n=0$，$b_n=\dfrac1n$ | $a_n\le b_n \Rightarrow$ 严格 $<$ |
| $f(x)=\sin\dfrac1x\ (x\ne0)$ | 局部有界 $\Rightarrow$ 极限存在；局部定号 |
| $f(x)=\sin 2\pi x$ | 数列收敛 $\Rightarrow$ 函数收敛（整数点全是 $0$） |
| $D(x)$（Dirichlet 函数） | 有界 $\Rightarrow$ 极限存在（处处不收敛） |
| $f(x)=x$ 或 $\lvert x\rvert$ | 函数正 $\Rightarrow$ 极限正；极限存在 $\Rightarrow$ 局部定号 |
| $f(x)=x$，$g(x)=-x$ | $A\le B \Rightarrow$ 局部 $f\le g$ |
| $f(x)=\operatorname{sgn}x$ | 极限不存在（左右极限不等） |
| $f(x)=\dfrac1x$，$x_0=0$ | 无界 $\Rightarrow$ 极限不存在（对照有界振荡） |
| $f(x)=\sin x$ | 整体有界 $\Rightarrow$ $x\to+\infty$ 极限存在 |

# 八、判断题检查清单

1. 有界是"**整体**"还是"**局部**"？函数题里出现"有界"先问范围。
2. 不等号是**严格**还是**非严格**？严格进才能严格出。
3. 极限值是否为 $0$？$A=0$ 是保号性的临界点，符号可任意摇摆。
4. 是否把"某个子列 / 某条路径"当成了"任意"？
5. 函数的 $f(x_0)$ 是否被误当成极限值？
6. "有界"要不要补上"单调"才能得收敛？
7. 单调有界时，问的是**极限存在**还是**函数值**？二者可以不等。

---

# 九、一句话收尾

> **收敛是有界的子集，严格正也是非负的子集；**
> **有界缺"单调"，正号缺"严格"——这就是两条性质反向失效的全部原因。**
> 数列与函数的差别只在"局部"的范围（从某项起 / 去心邻域），失效机制完全同构。
