## 课程简介

耶鲁大学经济系 ECON 159 是该校最受欢迎的公开课之一。课程从"什么是策略情境"讲起，用成绩博弈、囚徒困境、汉尼拔博弈、猜数字等例子逐步铺开占优策略、迭代剔除、最佳对策与纳什均衡；中段转入混合策略、进化稳定策略与序贯博弈（逆向归纳、子博弈完美均衡）；后段讨论重复博弈、不对称信息、信号传递与拍卖。

主教材：Dutta, *Strategies and Games: Theory and Practice*（课程主教材）；Watson, *Strategy: An Introduction to Game Theory*（更形式化）。讲义与英文讲稿见 [Open Yale Courses 课程主页](https://oyc.yale.edu/economics/econ-159)。

## 各讲一句话概要

- **L1**：博弈论研究"我的收益也取决于别人"的情境；成绩博弈给出五条入门结论——不玩严格劣势策略、理性可能带来糟糕结果、收益很重要、要设身处地、真实的人未必理性。
- **L2**：把博弈形式化（玩家 / 策略 / 策略剖面 / 收益），区分严格占优与弱占优，用汉尼拔博弈演示"先算对手"，并把猜数字游戏一路迭代剔除到 1，引出 common knowledge。
- **L3**：用迭代剔除解两党选举模型，得到中位选民定理（Downs 1957 / Hotelling 1929），逐条检讨其现实局限，最后引入最佳对策与信念。
- **L4**：点球博弈说明"射中间从不是最佳对策"，据此升级为"不要选择对任何信念都不是最佳对策的策略"；合伙制博弈引出纳什均衡 S\* = 1/(1−b) 与外部性。
- **L5**：纳什均衡的正式定义与两个动机（no regrets、self-fulfilling beliefs）；投资博弈展示多重均衡与坏均衡；银行挤兑与"沟通能救协调问题"。
- **L6**：Battle of the Sexes 是"有利益冲突的协调"；古诺双头垄断给出 q\* = (a−c)/(3b)，并比较垄断、古诺与完全竞争的福利。
- **L7**：只把"定产量"换成"定价格"，伯川德竞争就跳到完全竞争（p = c）；线性城市模型（作业）用来修补；候选人-选民模型则说明"两人都站中间"不再是均衡。
